# Misconception library

What a particular wrong answer usually means, and what a tutor can do in 30 seconds. Feeds each exercise's `feedback` (what the student sees) and `diagnose` (what the tutor sees). Add entries as real students show new patterns (`add-misconception` skill); mark each as **seen** (observed with a student) or **expected** (predicted, not yet observed).

## Scientific notation: form

| Pattern | Likely wrong rule | Tutor move | Status |
|---|---|---|---|
| Calls 45.6 × 10² scientific | "Has × 10ⁿ → scientific"; doesn't count digits before the point | Cover the × 10ⁿ; count the digits before the point | expected |
| Calls 10.5 × 10³ scientific | Same, and 10 "looks like one number" | Box each digit: 1, 0 — two digits | expected |
| Calls 3.25 scientific | "One digit before the point → scientific"; doesn't check for × 10ⁿ | "Where is the power of ten?" | expected |
| Calls 849.2 × 10⁴ a decimal | Doesn't treat × 10ⁿ as part of the number | Point to × 10ⁿ: "Is this part of the number?" | **seen** (user test, 2026-10-14) |
| Calls 4,560 or 0.004 "neither" | Thinks a decimal needs a point, or small numbers are special | Any plain number is a decimal | expected |
| Calls 6.2 × 10⁻⁴ "neither" | Thinks negative powers don't count | The power can be negative | expected |
| Calls 7 × 10⁵ "neither" | Thinks the front number needs a point | The point can be left off | expected |

## Powers of ten (for upcoming exercises)

| Pattern | Likely wrong rule | Tutor move | Status |
|---|---|---|---|
| ×10 "adds a zero" to a decimal (3.5 → 3.50) | Rule learned on whole numbers only | Show the digits shifting, not a zero appearing | expected |
| Moves the point the wrong way for ÷10 | Direction not linked to bigger/smaller | "Will the answer be bigger or smaller?" first | expected |
| Counts zeros instead of places moved | Confuses the number of zeros with the exponent | Count the jumps of the point | expected |
| Moves the point right for × 10⁻² | Reads the exponent's number and ignores the sign | Cover the number: "10⁻² means ÷ 100. Bigger or smaller?" | expected |
| Starts 45 × 10² from before the 4 | Doesn't see the hidden point at the end of a whole number | Write 45 as "45." first | expected |
| Stops at the front for 3.5 ÷ 10² | Doesn't know empty places become zeros | Show the faint zeros; the point hops onto them | expected |
| Moves the point left for 5.8 ÷ 10⁻² | Treats ÷ 10⁻ⁿ like ÷ 10ⁿ | Dividing by 10⁻² is × 10²; bigger or smaller? | expected |
| Moves the point for × 10⁰ | Thinks 10⁰ is 10 (or 0) | 10⁰ = 1; multiplying by 1 changes nothing | expected |
