## Candidates (from the older progressions and the user's earlier requests, not yet designed for the new set)

- Where the point goes for scientific notation (2.6, not 26.)
- Move the point with ×10 / ÷10 before typing the answer
- Decimal → scientific (big, then small numbers); scientific → decimal
- Powers of ten: ×10 and ÷10 on whole numbers and decimals, how many presses
- Fractions: cancel numbers and units, powers of ten, goal fractions; unit conversion

## Implicit review

When a later exercise uses an earlier skill (writing 2.6 × 10⁴ requires recognizing the form), the earlier exercise doesn't need separate drilling. If that ever becomes a feature, the later exercise's answers would count as review for the earlier one (Math Academy's "FIRe"; `evidence.md`).
