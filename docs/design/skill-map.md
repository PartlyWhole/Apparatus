# Skill map (the new set)

The exercises in order, what each needs first, and which later exercises review it implicitly. Update this when an exercise is added, reordered or retired.

| # | Exercise | Status | Needs first | Reviewed implicitly by |
|---|---|---|---|---|
| 1 | **Scientific or Not** (`sci-form`): decimal vs. scientific vs. neither | live | — | anything that writes or reads scientific notation |
| 2 | **Moving the Point** (`point-move`): × / ÷ 10ⁿ and × 10⁻ⁿ move the point | live | place value | factoring out powers of ten; decimal ↔ scientific |
| 3 | **Factor Out** (`factor-out`): decimal → scientific by moving the point; the power counts the hops | live | 1, 2 | Conversions |
| 4 | **Factor In** (`factor-in`): scientific → decimal; the power goes back into the number | live | 2, 3 | Conversions |
| 5 | **Conversions** (`conversions`): both directions, multiple choice then written | live | 3, 4 | |

## Candidates (from the older progressions and the user's earlier requests, not yet designed for the new set)

- Where the point goes for scientific notation (2.6, not 26.)
- Move the point with ×10 / ÷10 before typing the answer
- Decimal → scientific (big, then small numbers); scientific → decimal
- Powers of ten: ×10 and ÷10 on whole numbers and decimals, how many presses
- Fractions: cancel numbers and units, powers of ten, goal fractions; unit conversion

## Implicit review

When a later exercise uses an earlier skill (writing 2.6 × 10⁴ requires recognizing the form), the earlier exercise doesn't need separate drilling. If that ever becomes a feature, the later exercise's answers would count as review for the earlier one (Math Academy's "FIRe"; `evidence.md`).
