## The thinking behind the test

Every question reduces to a few moves on a grid:

| Move | What the student does | Test questions |
|---|---|---|
| **Δ (change)** | Count / subtract: how far right, how far up (signed) | 2, 4, 8, 16–20 |
| **Slope** | Rise over run: from a graph, from two points, from an equation | 3–10, 12, 13, 20 |
| **The other slope** | Parallel: same. Perpendicular: flip and change the sign. Horizontal ↔ vertical | 3, 5–8, 10–15 |
| **b** | Where the line crosses x = 0: b = y − m·x | 4, 7, 8, 10, 13 |
| **Midpoint** | The average of the x's and of the y's | 1, 16, 19 |
| **Distance** | Δx and Δy are legs of a right triangle; √(Δx² + Δy²), exact (simplified root) or scaled and rounded | 2, 17, 18, 20 |
| **Combine** | Perpendicular bisector; equidistant points; classify a quadrilateral by slopes and lengths | 16, 20 |

## The shared visual: the grid
A coordinate grid (SVG) with lattice points the student can tap. The anchor picture is the **slope triangle**: from one point, a run arrow (right/left) then a rise arrow (up/down) to the other — the same "hops" idea as the powers-of-ten set, now in two directions. Every exercise uses it as the cue after a miss:
- **slope:** the triangle with its run and rise labelled (signed);
- **perpendicular:** the triangle **turns 90°** — run and rise swap and one changes sign (rise 1, run 2 → rise −2, run 1). That's why perpendicular slopes are negative reciprocals, shown, not told;
- **midpoint:** the triangle cut in half; **distance:** the triangle's legs squared, the hypotenuse as the answer;
- **b:** run hops along the line back to x = 0, the y changing by m each hop.

## Answer formats (new building blocks)
- **Fraction** (slopes): two stacked boxes with the minus typed in the top box (like the exponent fields); simplified required, equivalent unsimplified answers get "simplify" feedback rather than a plain miss.
- **Point** (x, y): two boxes inside parentheses.
- **Equation** y = [m] x + [b], m a fraction; "y = [ ]" and "x = [ ]" for horizontal/vertical.
- **Root** a√b: a box, a radical sign, a box.
- **Graphing**: tap two lattice points to draw a line (G11, Q16A).

## Example feedback (pick-specific, as before)
- Slope with run and rise swapped: "Rise goes on top: up 3 for every 1 across is 3, not ⅓."
- Perpendicular with only the sign changed: "Turned 90°, rise and run swap too: the perpendicular to 2 is −½."
- Distance not simplified: "√153 = √(9 · 17) = 3√17."
- Midpoint as a difference: "Halfway is the average: (1 + 11) ÷ 2 = 6."
- b with the sign of m·x wrong: "b = y − m·x = −9 − ¼·(−4) = −8."

## Decided (2026-10-14)
- Fractions: stacked boxes; a minus typed in either box; empty bottom = 1; "undefined" is a chip.
- An equal but unsimplified answer (2/4) gets a "Simplify." nudge and isn't graded.
- Built in `geometry/` with its own libraries (`geometry/lib/`: grid, frac, lines, geo.css, page) and its own analytics page (`geometry/analytics.html`), so it doesn't touch the science set.
